## 结论

收到的 `expression.h5ad` 可经 h5py 读取，包含 4 个细胞、2 个特征、2 个 specimen 的转换后表达及 core 局部坐标，可作为描述性表达汇总和各 core 内空间展示的候选输入。没有原始计数、生物学重复映射或细胞类型标签；不支持据此直接开展要求原始计数的方法、细胞类型组成分析或具有生物学重复依据的组间推断。AnnData 读取兼容性未测试。

接收目录完整枚举后，确认邮件承诺的三个 MEX 文件均缺失。README 声称“H5AD-only”，但没有后续协议修订证据，因此不能判定原约定已经满足。H5AD 的可用内容不能替代对指定 MEX 路径的履约核对。未计算校验和，未验证与源端字节一致性。
