# Coordinator-only evaluation criteria

The intake, analysis and scope criteria are verbatim copies of the coordinator's original criteria files. The conflict criterion records the coordinator's separate packaging instruction. All four were **not supplied to the candidate agents** during their behavioral trials. They are included separately for later assessment, not as candidate inputs or evidence that a criterion passed.
