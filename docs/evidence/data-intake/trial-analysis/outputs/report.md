## 摘要

本包提供 **4 个细胞 × 2 个特征、两个 core（A、B）** 的处理后表达、完整的对象内坐标及可按键对齐的注释，可用于现有表达和注释的描述性检查、按 core 分开的空间展示。`coordinates.csv` 未完整对应表达对象：缺少 `(B,c2)`，多出 `(B,c9)`；对象内 `obsm/spatial` 仍覆盖全部 4 个细胞。

原始计数未导出，不能据此进行需要原始计数的分析或重新执行上游归一化。生物学重复身份未提供，不能把 core 或细胞当作独立动物/肿瘤进行组间推断。尚未选定分析，不据此提出方法专属门槛。

## 检查结果

先执行元数据扫描，再对这个小包全量检查；覆盖 H5 中两份矩阵各 8 个值、4 个细胞及两个 CSV 各 4 行，无抽样。

| 项目 | 观察及影响 |
|---|---|
| 表达和特征 | `X` 与 `layers/scaled` 均为可读的稠密 4×2 矩阵，obs/var 长度对齐；无非有限值、全零细胞或全零特征。`G1`、`G2` 标签唯一且非空，但其生物学标识类型及原始面板关系未知。`X` 范围 0–0.9；scaled 范围 −1.5–1.5，4 个负值符合所声明的中心化表示，不构成计数错误。不存在 raw/count 层，不把两者解释为原始计数。 |
| 细胞身份 | obs 顺序为 `(A,c1),(A,c2),(B,c1),(B,c2)`。单独条码重复，复合键 `(core,cell_id)` 全部唯一、无缺失；符合 README 的作用域。 |
| 注释连接 | CSV 复合键唯一，无缺失或额外键，4/4 一对一匹配。CSV 顺序不同，须按复合键对齐；对齐后标签为 `T,B,B,T`。标签非空，各 2 个；只确认对应关系，不验证标签生物学含义或准确性。 |
| 对象内空间坐标 | 4×2 坐标全部有限；A、B 各 2 个细胞，分别 x=0–1、y=0–2 µm，无塌缩轴、core 内重复坐标。跨 core 的两组坐标重复符合 README 的独立局部坐标系；未来建图须按 core 隔离，不能由数值重叠连接 A、B。单位与框架来自 README，未作独立标定。 |
| 坐标 CSV | 复合键唯一、数值有限，但只有 3/4 对象键匹配：A 为 2/2，B 为 1/2。缺 `(B,c2)`、额外 `(B,c9)`；三个匹配键的坐标均与对象完全相同。相同行数不能证明对应；不得按行或坐标值把 c9 改作 c2。A 全部及 B/c1 是有效匹配子集；对象内坐标仍完整。 |
| 样本与组别 | core、group 均无缺失或内部冲突，A→control、B→case。每组仅一个 core；没有动物/肿瘤/供体身份或独立性证据。core 可以分开进行空间检查，但生物学重复关系未知。 |

证据：[元数据结果](expression-metadata.json)、[全量检查结果](expression-full.json)、[完整对象值与复合键连接结果](04_joins.log)。检查器的 `errors=[]` 仅表示其所覆盖检查未报错，不消除上述 CSV 缺陷或解释限制。
