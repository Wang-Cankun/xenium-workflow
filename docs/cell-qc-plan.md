# Xenium 细胞级 QC：探索计划与证据

## 目标与范围

现有 `xenium-quality-check` 只描述数据，不做过滤决定；路由器要求“选择或应用过滤规则”另立范围。本文记录为这一空缺建立细胞级 QC 模块所做的探索：先以一个真实的 Xenium Prime 5K 队列检验候选指标与规则，再把得到支持的做法写成模块。

QC 按分析阶段划分，每个阶段回答不同的问题，由各自的模块负责：

| 阶段 | 回答的问题 | 本轮 |
|---|---|---|
| 交付与输入 | 文件是否齐全，矩阵、细胞表和坐标是否对应 | 已由 data-intake 和 analysis-input-check 负责 |
| 描述性 QC | 数据规模、各区域信号和原生指标是什么样 | 已由 quality-check 负责 |
| 细胞级 QC（聚类前与聚类后） | 哪些细胞信息不足或可能是伪影，如何标记、排除或救回 | **本轮** |
| 注释后 QC | 标签是否可信、是否存在混合信号或溢出 | 第一轮只做内部诊断；跨队列评估后由 `xenium-annotation-qc` 负责 |

## 证据

| 来源 | 与细胞级 QC 相关的结论 | 适用范围与局限 |
|---|---|---|
| Marco Salas et al., *Nat Methods* 22:813 (2025), [doi](https://doi.org/10.1038/s41592-025-02617-2) | 25 个 Xenium 数据集中只排除少于 10 个转录本的细胞（约 0.2%）。在模拟基准中，归一化方式、目标文库大小、是否 scaling 和主成分数是影响聚类最大的因素；最佳流程为文库大小归一化到 100、log、scaling、用全部主成分建 16 近邻图。默认核分割足以识别主要细胞群 | 以靶向面板为主，不是 5K；基准以已知细胞群为金标准 |
| “Resolving sensitivity, specificity and signal contamination in Xenium spatial transcriptomics”（提出 SPLIT），*Nat Methods* (2026), [doi](https://doi.org/10.1038/s41592-026-03089-8) | 5K 面板灵敏度低于靶向面板，约 60% 的细胞因转录本数低而未通过其 QC。其 Xenium 过滤只排除少于 10 个计数或 5 个基因的细胞，再用 RCTD（doublet 模式，降低 UMI 下限）处理低计数和混合信号。混合信号主要来自相邻细胞的转录本溢出，与邻域中该类细胞的丰度相关 | 需要 snRNA 参考；乳腺和肺肿瘤 |
| OSTA（Bioconductor）成像空间转录组 QC 章节，[页面](https://bioconductor.org/books/release/OSTA/pages/img-quality-control.html) | 转录本数与细胞面积应密切相关，用每面积计数的 log 尺度 MAD 找下侧离群；可排除任何对照探针计数不为零的细胞（较严格）。排除前先看被排除细胞在组织中的位置：若在空间上成片，可能是在系统性删除某类细胞（例如较小、计数较少的免疫细胞） | 依据检索到的页面摘录，未通读全章；示例为 313 基因的 Xenium 数据。对照计数 >0 这一条在 5K 面板上需要重新评估 |
| SpaceTrooper，bioRxiv (2025), [doi](https://doi.org/10.64898/2025.12.24.696336)；Bioconductor 包 | 用岭回归逻辑模型把细胞面积、信号密度（计数/面积，log2）、背景（对照探针占比，log2）合成一个质量分数；训练用的高低质量样本由基于分布的离群检测给出。Xenium 数据没有 FOV 边缘伪影，长宽比一项只用于 CosMx | 预印本；阈值仍需按数据选择 |
| CyLinter, *Nat Methods* 21:2248 (2024), [PMC11621021](https://pmc.ncbi.nlm.nih.gov/articles/PMC11621021/) | 多重成像蛋白数据的 QC 框架：按模块迭代（感兴趣区域、DNA 强度、分割面积、离群值），每一步都在图像上叠加显示，供人复核。metaQC 把被删和保留的细胞一起聚类，被删细胞若落在“干净”的簇里就加回，保留细胞若与噪声细胞同簇就移除。伪影会形成自己的簇 | 蛋白成像，不是转录组；原则可以迁移 |
| Mitchel et al., *Nat Genet* (2026), [doi](https://doi.org/10.1038/s41588-025-02497-4) | 据引用它的二手来源：分割错误会把转录本错分给相邻细胞，影响差异表达、细胞互作和状态推断 | 原文和摘要都未取得（非开放获取）；需读原文后再引用具体结论 |
| Plummer et al., *Nat Biotechnol* 44:1213 (2026) | 题目为成像空间转录组的标准化质量和重复性指标 | 只见于他处的参考文献列表，未读原文 |
| ovrlpy（Tiesmeyer et al., *Nat Biotechnol* 2026, [doi](https://doi.org/10.1038/s41587-026-03004-8)）；ResolVI（Ergen & Yosef, *Nat Methods* 2026, [doi](https://doi.org/10.1038/s41592-026-03212-9)） | ovrlpy 用上下两层虚拟切片的表达相似度（VSI）找垂直重叠和折叠；ResolVI 用生成模型把观测表达分成自身表达、邻居扩散和背景 | 第一轮只见于 SPLIT 的引用；跨队列评估中实际运行，其对默认值的影响见 [evidence](../skills/xenium-cell-qc/references/evidence.md#basis-of-the-defaults) |

归纳：

1. **固定低门槛加上数据驱动的标记，而不是高的全局门槛。** 公开流程在 Xenium 上只用很低的固定门槛（约 10 个转录本），其余用分布自适应的离群检测或综合评分来标记。
2. **5K 面板天然计数低。** 5K 中低计数细胞比例高；直接提高门槛会删掉大量细胞。已有做法是用参考映射或反卷积处理这些细胞，而不是删除。
3. **密度比总数更合适。** 转录本数随细胞面积变化，所以用每面积计数判断信号不足更合理。
4. **看被删细胞在哪里、是谁。** 被标记的细胞如果在空间上成片或集中在某类细胞，就要先查原因。
5. **预处理可能制造出“低质量簇”。** 聚类结果对归一化和 scaling 很敏感；低深度细胞自成一簇，可能部分来自预处理。
6. **聚类可以反过来帮助 QC（metaQC）**，但需要空间和形态证据配合，不能单凭簇的归属删除细胞。

## 预先登记的实验

候选的每细胞特征：基因转录本数、检测基因数、每面积转录本密度、细胞面积、细胞核面积、核/细胞面积比、细胞核数、对照探针和对照码字计数、细胞核内转录本比例（需要转录本级字段）、形状长宽比（需要边界）、到组织边缘的距离、局部细胞密度。

候选规则族：

- **A 固定门槛**：10/5、20/10、50/10（转录本/基因）。
- **B 按区域的 MAD**：每个区域内 log 转录本数低于中位数减 3 个 MAD。
- **C 按区域的每面积密度 MAD**：OSTA 的做法，在每个区域内计算。
- **D 对照信号**：对照计数 >0，以及对照占比高于区域分布的上侧离群。
- **E 综合质量分数**：仿 SpaceTrooper，用岭回归逻辑模型组合面积、密度和对照占比，训练样本来自 B–D 的离群。
- **F 按聚类回看**：仿 CyLinter metaQC，找出被标记细胞占多数的簇，再结合空间和形态证据决定整簇标记或加回。

评价标准（在看结果前确定）：

1. 各区域和各来源文件夹的保留率，以及保留率与区域中位深度的关系；
2. 被标记细胞到组织边缘的距离，与未标记细胞比较；
3. 被标记细胞的形态（面积、核面积、核/细胞比）；
4. 被标记细胞在各临时大类中的比例（大类由高质量细胞的 marker 得分给出），以此判断是否偏向删除某类细胞；
5. 在推荐的预处理下，过滤后是否还出现由单一高丰度转录本定义的低深度簇；
6. 各区域主要大类的比例在不同 QC 口径下是否稳定。

预处理敏感性：比较归一化目标（1e4 与数据中位数）、是否 scaling、全部基因与 HVG、Pearson 残差，以及只用高质量细胞拟合 PCA 再投影其余细胞。看低深度簇是否还会出现、marker 是否一致、run 混合度如何。

低信息细胞的处理：只用高质量细胞建聚类结构，再用 kNN 标签转移给低信息细胞类别和置信度；用空间邻居一致性和 marker 一致性评价，置信度低的标为 unresolved。

## 产出与模块边界

探索结果写成项目报告；得到支持的做法写成新模块（暂名 `xenium-cell-qc`）。这个模块只负责细胞级标记与排除的决定：输出标记列和理由，不删除原始对象；阈值和规则的选择记录在项目里。描述性指标仍由 `xenium-quality-check` 负责，注释后的 QC 以后另定。

## 结果

实验已完成，结论写入模块 [xenium-cell-qc](../skills/xenium-cell-qc/SKILL.md)：默认值和依据见
[evidence](../skills/xenium-cell-qc/references/evidence.md)，救回与污染诊断的做法见
[label-rescue](../skills/xenium-cell-qc/references/label-rescue.md)。真实数据的完整证据保存在使用方项目中。
第二个队列（定制靶向 panel 的 TMA）上的试验经过和由此修改的默认值见
[skill-trials](skill-trials.md#targeted-panel-tma-trial)。
与预注册的差异：规则 F（按聚类回看）做了评估，但在基础规则下没有一个簇的被标记细胞超过一半，所以没有作为规则采用；低信息细胞改用“参考细胞 + 标签转移”处理。注释后 QC 只做了内部污染诊断。

第三轮在该靶向 panel 的多个 run 上做了跨队列评估（多个 XOA 版本、多物种设计），同时对照已发表方法和多个合作方已有的 QC 与注释，评估方案在看结果前确定。由此修改的默认值及其依据见
[evidence](../skills/xenium-cell-qc/references/evidence.md#basis-of-the-defaults) 和
[skill-trials](skill-trials.md#cross-cohort-evaluation)；注释后 QC 由新模块
[xenium-annotation-qc](../skills/xenium-annotation-qc/SKILL.md) 负责。
